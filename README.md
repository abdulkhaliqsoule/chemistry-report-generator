# Chemistry Report Generator

The earliest version of the clinical chemistry report generator, covering five
panels: renal, liver, lipid, glycated haemoglobin and uric acid.

    python lab_report_5panels_commented.py

Needs Python 3.8+, `pdfplumber` and `reportlab`.

Superseded by LabScribe and kept for reference. The `reports/` folder and all
PDFs are ignored by git because they hold real patient reports — keep it that
way.
